# Amplify Inspirations Media — legal pages

Public Terms of Service and Privacy Policy, served by GitHub Pages. These URLs are submitted
to platform app reviews (TikTok, Meta/Instagram, Google/YouTube), which require both to be
publicly reachable without a login.

| Page | URL |
|---|---|
| Home | `https://<org>.github.io/legal/` |
| Privacy Policy | `https://<org>.github.io/legal/privacy.html` |
| Terms of Service | `https://<org>.github.io/legal/terms.html` |

## Editing

Plain static HTML, no build step. Edit and push; Pages redeploys in about a minute.
Update the "Last updated" date at the top of any page you change.

## Do not delete: TikTok URL verification

`tiktokSZOD3LSNrXCqxpgt1tTOmmBgUBmeatFk.txt` proves to TikTok that we control the
`/legal/` URL prefix, which is what lets the Content Posting API accept our Terms and
Privacy Policy URLs. TikTok **re-checks it periodically** — deleting or renaming it
un-verifies the app and breaks publishing. It must keep its exact filename, its exact
contents, and no trailing newline.
